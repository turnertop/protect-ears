Fixes a detection failure where connected AirPods Max could disappear from Protect Ears and Refresh would repeat Core Audio error `2003332927` (`who?`, unknown property).

## Fixes

- A failed or unsupported query on one device no longer cancels discovery of every output.
- Default outputs and remembered headphone identities are checked independently of the global device list.
- Repeated discovery failures rebuild this app's Core Audio connection, discarding old object IDs and reinstalling listeners. Refresh can request the same recovery; a cooldown prevents reset loops.
- Error details now identify the object, property, and scope. The app states explicitly when detection is unavailable and the ceiling cannot be verified.
- Adds simulated regression checks for partial device failures, global-list failures, renamed headphones, reused IDs, and recovery behavior.

## Download and install

The **DMG** and **ZIP** both contain the universal app for Apple silicon and Intel Macs, requiring macOS 13 or later. Move the app to Applications, quit an older running copy, and open the updated app. There is no automatic updater. Keep your existing four/five-step ceiling; preferences use the same bundle identifier.

The release is **ad-hoc signed, not Developer ID signed or notarized by Apple**. macOS may block it on first open. Only if you trust the download, follow [Apple's instructions for allowing the individual app](https://support.apple.com/en-us/102445). Do not disable Gatekeeper or remove quarantine attributes.

**We do not know whether Protect Ears will protect your hearing. It has not been proven to prevent hearing damage. Do not rely on it as hearing protection.** Loud spikes can still get through before correction. See the [full disclaimer](https://github.com/turnertop/protect-ears/blob/v1.0.1/DISCLAIMER.md).
