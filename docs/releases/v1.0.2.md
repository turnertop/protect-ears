Fixes delayed volume correction during repeated volume-up requests. Full device scans no longer run ahead of corrections on the volume-monitoring queue.

## Changes

- Volume notifications check cached selected headphones on a dedicated queue. Device discovery and listener maintenance run separately.
- Coalesces duplicate notifications, bounds background discovery during metadata storms, and delivers only changed UI state. Quiet volume checks read each control once.
- Checks selected headphone volume every 100 ms if notifications are missed, and stops volume polling while no selected outputs are connected.
- Caches control addresses, refreshing them for device/profile changes and recovery. Fresh identity checks before writes or emergency muting prevent stale device IDs from affecting a different output.
- Adds regression checks for blocked discovery, notification bursts, fallback correction, stale reconnect scans, bounded idle work, UI delivery, and serialized Core Audio recovery. All 49 simulated checks pass locally.

A silent, controlled test of the running app corrected all 60 programmatic volume-up requests before the following request, with a 20.9 ms median and 25.9 ms maximum observed correction time. A short connected idle sample measured 0.40% of one CPU core and 25.44 MiB physical memory. These observations are specific to one Mac and test run, not timing or resource guarantees. Details and remaining physical-device checks are in the [verification checklist](https://github.com/turnertop/protect-ears/blob/v1.0.2/docs/verification-checklist.md).

## Download and install

The DMG and ZIP contain the universal app for Apple silicon and Intel Macs, requiring macOS 13 or later. Quit an older running copy, replace it, and open the updated app. There is no automatic updater. Your saved ceiling and selected devices are preserved.

The release is **ad-hoc signed, not Developer ID signed or notarized by Apple**. If macOS blocks it and you trust the download, follow [Apple's instructions for allowing the individual app](https://support.apple.com/en-us/102445).

**We do not know whether Protect Ears will protect your hearing. It has not been proven to prevent hearing damage.** The guard reacts after a volume change; brief spikes can still get through.
