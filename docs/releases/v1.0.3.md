Preserves your Start at login choice through updates. The app now saves your preference instead of relying solely on the current macOS registration.

- On the first launch of an updated build, a missing login registration is restored if you previously chose On. Off stays off.
- The build marker includes the code signature and installation location, covering local rebuilds and moves as well as version changes.
- macOS approval requirements remain in place. Registration failures stay visible with a Retry action; activation events do not repeatedly register the app.
- A local update script preserves the old choice and unregisters the old copy before backing it up, then installs and opens the replacement. The next launch restores the saved choice, including after a rollback.
- Adds simulated checks for migration, On/Off persistence, external removal, pending/revoked approval, failures, retry limits, and update handoff.

**Open the updated app once after replacing the old copy.** Versions 1.0.2 and earlier did not save the login preference; check Start at login once when upgrading from those versions. With locally signed builds, removing the entry while the app is closed and then manually replacing the app is ambiguous. Open the old app once after removal or use the local installer so it can record that Off choice before updating. See the [README](https://github.com/turnertop/protect-ears/blob/v1.0.3/README.md#keeping-start-at-login-through-updates).

The five/four-step volume behavior is unchanged. The DMG and ZIP support Apple silicon and Intel Macs running macOS 13 or later. Preferences retain the same app identifier.

This release is **ad-hoc signed, not Developer ID signed or notarized by Apple**. If macOS blocks it and you trust the download, follow [Apple's instructions for allowing the individual app](https://support.apple.com/en-us/102445).

**Protect Ears has not been proven to protect hearing or prevent hearing damage.** It reacts after volume changes; loud spikes can still get through. See the [full disclaimer](https://github.com/turnertop/protect-ears/blob/v1.0.3/DISCLAIMER.md). MIT licensed.
